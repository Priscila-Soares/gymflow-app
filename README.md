# GymFlow

GymFlow é uma aplicação web fullstack desenvolvida para gerenciar treinos de academia e acompanhar a evolução física de alunos.

O sistema permite cadastrar alunos, registrar exercícios, criar treinos personalizados e acompanhar o progresso físico ao longo do tempo.

## Tecnologias Utilizadas

### Backend
- Java
- Spring Boot
- Spring Data JPA

### Frontend
- Angular

### Banco de Dados
- MySQL

### Ferramentas
- GitHub
- GitHub Projects
- Postman
- draw.io (diagramas)

## Arquitetura

A aplicação segue uma arquitetura em três camadas:

Frontend (Angular)  
⬇  
Backend API (Spring Boot)  
⬇  
Banco de Dados (MySQL)

O frontend consome a API REST desenvolvida em Spring Boot, responsável pelas regras de negócio e comunicação com o banco de dados.

## Estrutura do Projeto

gymflow-app
backend → Spring Boot
frontend → Angular
database → scripts SQL
docs 


## Funcionalidades do Sistema

- Cadastro e gerenciamento de alunos
- Cadastro de exercícios
- Criação de treinos personalizados
- Registro da evolução física dos alunos
- Visualização de histórico de progresso

## Gerenciamento do Projeto

As tarefas do projeto são organizadas utilizando **GitHub Projects (Board)**.

Cada funcionalidade é desenvolvida de forma incremental, seguindo as entregas da disciplina.
